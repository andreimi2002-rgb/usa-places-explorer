# America 360 — VS Code starter kit

1. Extract this folder. Open it in VS Code as a new independent project, or copy the master brief and `references/` into a dedicated existing America 360 workspace. Do not overwrite an unrelated project.
2. Open your coding agent (Codex, Copilot Chat in agent mode, or equivalent). Give it the following initial instruction:

> Read `MASTER_DEVELOPMENT_PROMPT.md`, `START_HERE.md`, and every file in `references/`. This is the definitive project brief. Audit the current workspace, then implement Phase 0 and Phase 1 with real code and tests. Do not stop at a plan or another static mockup. Use the Florida/Jacksonville demos as references. Keep America AI and Life Simulator for later, but preserve their architectural requirements. Prioritize the reusable encyclopedia foundation and Florida. Work locally; no paid API calls, deployment, or deletion of unrelated files. At the end, give me exact commands to run the site, the actual test results, what is implemented and what remains. Update docs/PROGRESS.md.

3. Review the first local build before committing to additional phases. To resume, ask the agent to read the master brief and the progress log, verify the current state, and implement the next incomplete milestone.

The references are existing reconstructed HTML prototypes and the earlier v0.1 plan, not production source or a complete Florida database. The master brief supersedes conflicting earlier plans. No framework project or credentials have been created by this kit.
